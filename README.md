# ShardVase

> 让每一份软件授权都像碎瓷片一样——**唯一、不可复制、坏了看得见**。

ShardVase 是一套 Windows x64 软件的**反逆向保护 + 离线授权**能力包：
把你的软件跑进虚拟机器、钉死机器、签发绑定授权，**默认完全离线、零遥测**。

技术上是我们的自研实现（不是套壳），安全强度有公开的攻防演练记录可查；
本文档页是**能力介绍与诚实边界**，不是营销话术。

---

## 它解决什么问题

| 痛点 | 方案 |
|------|------|
| 软件被破解/被逆向学习 | 自定义 VM 混淆执行 + 自加密函数 + 多因子反调试 + 完整性自检 |
| 一份授权到处拷贝 | RSA-3072 机器绑定：换机即失效（签名载荷含机器硬件标识） |
| 试用/分级管理混乱 | 授权载荷内含 tier（试用/正式/高级）与到期时间，签名防篡改 |
| 授权怎么发、改、查 | 自持签发体系：私钥在自己服务器，台账哈希链防篡改，支持离线签发 |
| 客户离线环境 | 运行期零网络、零遥测（默认），可完全离线部署 |

## 能力与证据（每项都有测试依据）

- **VM 混淆执行**：自定义字节码引擎 + 跨构建变异（操作数与折叠公式随构建变化），
  引擎函数运行期原位加解密（明文窗口 = 活动周期）→ 见攻防记录 R1/R3、F1；
- **反调试**：PEB/断点/内核/时序/堆标志多因子，0 误报基线（干净环境验证）；
- **完整性**：`.text/.rdata/.pdata` CRC + 看门狗周期复查（含授权数据冗余校验）；
- **反注入/反 hook**：Frida/Xposed/DBI 特征扫描（周期复查）；
- **授权**：RSA-3072 + 机器绑定 + tier/expires + VM 判定链融入；
  blob（VM 镜像包）与黑名单均签名，防替换防回滚；
- **签发与台账**：服务器签发 + 重放拦截 + 哈希链台账（记录不可静默更改）；
- **接入**：`prot_sdk` 骨架与向导，开发者 3 步入场（见 QUICKSTART）。

## 诚实边界（我们已知且公开）

- **没有"永不破解"**：这是安全产品的常识，我们不承诺；
  已实证的边界包括：安装目录可写时可换公钥重签（D2a 类）、
  到期控制依赖本地时钟（可回拨）、完整内存转储可取证明文窗口。
  作恶成本与缓解均在 [boundaries](boundaries.md) 说明。
- 当前支持：Windows x64（C/MSVC 生态）；Android 骨架就绪未发布。
