## 它解决什么（一句话）

你的软件被破解、被换机共享、授权管理靠手工 Excel——ShardVase 把这四件事
变成：**VM 混淆执行 + RSA-3072 机器绑定 + 自持签发体系**，默认完全离线、
零遥测。

## 真实运行的演示（不是示意图）

演示包是一个被完整保护的小工具（批量 SHA-256 校验）。这是它被保护后
的真实输出：

```
== 反逆向保护套件演示 ==
反调试扫描: 通过
机器标识:0x5e6bfd7560985c95
请输入序列号:license: 1 (tier=1 expires=17xxxxxx)
== 批量哈希校验工具 (正式版) ==
机器绑定: 0x5e6bfd7560985c95  授权: Tier1
  hashcalc.exe:131ef2cb1bb5e53a...
```

现在请你对它做这些——**每一条都会失败**：

| 你试一下 | 结果 |
|----------|------|
| 改 license 任意一个字符 | `license: 0`，拒绝运行 |
| 把授权拷到另一台电脑 | 拒绝（绑定在签名载荷里，文本只是说明）|
| 换掉 vm.blob（伪造/篡改）| VM 镜像装载失败 |
| 把系统时间调到过期日之后 | 拒绝（评估到期）|
| 调试器附加 | 反调试多维检测 |

## 能力速览（每条都有证据）

| 能力 | 说明 |
|------|------|
| VM 混淆执行 | 自定义字节码引擎 + 跨构建变异；引擎函数运行期原位加解密，明文窗口=活动周期 |
| 多因子反调试 | PEB/断点/内核/时序/堆标志；干净环境零误报基线 |
| 完整性守护 | .text/.rdata/.pdata CRC + 看门狗周期复查（含授权数据冗余校验）|
| 机器绑定授权 | RSA-3072；serial/tier/到期/机器码全部卷入签名，改一个字节即失效 |
| 防镜像替换 | VM 镜像包与授权同私钥签名；黑名单（吊销）亦签名 |
| 自持签发体系 | 私钥只在你的服务器；防重放；台账哈希链防静默篡改；离线签发 |
| 接入向导 | prot_sdk：三步接入（生成工程 → 写业务 → 构建+授权闭环）|

## 快速开始（3 分钟）

1. 下载[演示包](https://github.com/auui-LDAH/ShardVase-demo/releases)（v1.0.0，含 7 天评估授权）；
2. 解压后运行（输入序列号 `DEMO-2026-ABCDEFGH`）；
3. 按上面的表格动手"破坏"它——验证保护是真的。

演示包到期？这是授权流程的一部分：运行包内 `req_gen.py` 生成 `.req`，
开 [Issue：评估申请](../../issues/new?template=eval.yml) 附上，我们签发
14 天续期授权。

## 接入自己的软件

面向 C/MSVC（Windows x64）开发者：生成骨架工程 → 在
`prot_business_main(ctx)` 写业务 → 一键构建。授权/签发/到期/换机
全部内置，你的客户体验完整闭环。

想知道适不适合你的项目？开 [Issue：接入咨询](../../issues/new?template=consult.yml)，
或邮件 `shardvase@<域名>`（上线后公布）。

## FAQ

**Q: 和 XProtect/Themida 比怎么样？**
A: 我们的定位不同：不只卖"壳"，而是保护+授权+签发+审计的一体化，且
源码可以给你的开发机接入调试。适用 C/MSVC x64 生态。

**Q: 会不会被杀软误报？**
A: 自修改/加密类程序天然容易触发行为检测。我们有发布版收敛策略与
申诉流程；正式使用建议配代码签名证书（这是行业通例，非缺陷）。

**Q: 离线方案能在线吗？**
A: 默认完全离线；在线签到/实时吊销是可选模块（客户自己的端点），
当前未发布。

**Q: 你能承诺"不破解"吗？**
A: 不能，也不建议任何方案这样做。我们能给的是：攻防档案、诚实边界、
持续更新。
